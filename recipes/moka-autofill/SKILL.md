# Moka 校招简历填写配方（moka-autofill）

适用：Moka 校招候选人端**两类页面**——① 在线简历页 `app.mokahr.com/campus-recruitment/<机构>/<id>#/candidateHome/resume`；② 职位申请表 `app.mokahr.com/campus-recruitment/<机构>/<id>#/job/<jobId>/apply?applyFormId=<id>`。两者字段集与按钮结构都不同（见 §一 末条、§五、§六），套用前先判是哪一类。
首次实战：2026-09-17 银华基金（投递台账序号 32）。本项目现场侦察重建，只记本系统结构与手法，通用纪律见 `CODEBUDDY.md`。

## 1. 框架与 DOM 骨架

- 框架：React（旧版，元素上挂 `__reactInternalInstance$<hash>` / `__reactEventHandlers$<hash>`），组件为 Moka 自研 `sd-*` 系（非 antd、非 element-ui）。
- 字段容器：`.apply-field-Q2iJ7AtQGX`，标题在子 `.title-IWWQ0Xa4L7`；区块（教育背景／实习经历等）内字段按 DOM 顺序排列，同名标题按出现次序（occ）区分。
- 区块添加按钮：文案「添加」；每条记录另有「删除本条」。
- **页面类型决定按钮结构**：① 在线简历页（银华实例）底部有「保存」按钮，保存＝整页提交，不做逐条保存；② 职位申请表（嘉实实例）**全页无「保存」按钮**，只有一个「预览并提交」，另有左侧区块导航与底部「更新说明：同步更新在线简历」勾选——此类页面填完**无法自查落库**，只能进预览页。

## 2. 四类控件与写入通道

| 控件 | 识别 | 写入方式 | 值落在哪 |
|---|---|---|---|
| 普通文本输入 | `input`，`maxlength=255`（姓名／所在地／最近公司／证件号码／当前薪资／期望薪资／期望城市／公司名称／职位名称／项目名称／职责／语言类型／奖项名称） | 真实键入：取 snapshot 编码索引 → `ego_fill`（真实输入；按 locator 定位，索引会变则重取 `ego_snapshot`） | `input.value` |
| 多行文本 | `textarea`（工作职责／项目描述／项目中职责／自我描述），无 maxlength | 同上；文本内含 `\n` 可真实换行，保存回读后换行保留 | `textarea.value` |
| 字典下拉 | 字段内含 `.sd-Dropdown-container-1CigZ`，`input` 只读展示（性别／工作经验／最高学历／学历／掌握程度／听说／读写／年／月） | **只能点选**：点 input 展开 → 在字段容器内找可见 `.sd-Select-menu-36GwS` → 点 `.sd-Select-common-item-3YCIH` 中文本匹配项 | `span.sd-Input-display-value-RwqDy`（`input.value` 恒为空） |
| 远程联想 | 同下拉结构但可键入（学校名称／专业名称） | 键入后**必须点选候选项**；仅键入不入 React state，后续任何 re-render 会静默清空 | `span.sd-Input-display-value-RwqDy` |

开层与点选都要派发完整合成事件序列（缺一不开层）：
`pointerover → mouseover → pointerdown → mousedown → focus → mouseup → pointerup → click`，
事件须带 `clientX/clientY`（取 `getBoundingClientRect` 中心）、`view: window`、`bubbles: true`。

## 3. 日期类字段

- 起止／就读／获奖时间＝**年、月两个独立下拉**（开始年、开始月、结束年、结束月），按字段内 `.sd-Dropdown-container-1CigZ` 的第 0/1/2/3 个定位。年份选项为纯数字、倒序（2126→1926，共 201 项）；月份为 `1`–`12`。
- 精度只到月，无「日」。按 `CODEBUDDY.md` §一.$1，回读到月即算对齐。
- 有「至今」复选框（实习／项目区块），在读经历不勾（结束时间已填具体月份）。
- 出生日期：`readonly` input，展开后是年月面板（`sd-panal-*`），点选年份 + 月份；值形如 `2001-07 (25岁)`，写入 `input.value`。

## 4. 新增条目

- 「添加」按钮在文档中的序号**会随条目数变化**（每新增一条记录就多一个「删除本条」按钮），固定序号法第二次起即错位。
- 可靠定位：按区块标题（如「实习经历」）元素取 `getBoundingClientRect().top`，在按钮集合中取 top 差值最小且 ≥ −40 的「添加」按钮；「删除本条」同理并可加 nth。
- 点击用 §二 的完整合成事件序列；缺 `pointerdown`/`focus` 时点击可能静默无效，缺 `getBoundingClientRect` 坐标时组件抛错。
- 新增后 React 重排，已填值可能串位或丢失：**每加一条就整页回读一次**，不要在未回读的情况下连续加多条。

## 5. 回读与保存

- 整页回读须同时取 `input/textarea.value` **和** `span.sd-Input-display-value-RwqDy` 文本——下拉与联想字段的值只在后者，只读 value 会全部显示为空，误判为未填。
- ⚠️ **「上传简历」是破坏性操作**（2026-09-18 嘉实职位申请表实测，事故级，有 `CODEBUDDY.md` §一.$1 背书）：点它会触发 Moka 自动解析 PDF 并**覆盖已填内容**。本轮实测受损面：教育的学院名称与 GPA 被清空；实习由 4 条降至 3 条，且公司名称／职位名称／工作地点／工作职责被换成 PDF 里的写法；项目 2 条全清；自我描述由 488 字变 50 字。附件与表单内容互不干扰（使用者手动上传附件不影响脚本改字段）。**正确顺序是先传附件再填表**；若已填完才上传，必须整表回读逐项修复，不得因「解析已完成」放行。
- 保存：在线简历页底部有「保存」按钮（文本定位，全套合成事件）；**职位申请表无保存按钮**，只有「预览并提交」，未点即未落库（投递动作按 `CODEBUDDY.md` §一.$1 须用户明确指示）。页面内嵌网易易盾验证码组件，保存/提交环节可能弹出，需用户手动完成。
- 保存判据：`CODEBUDDY.md` §一.$1 —— 用 CDP `Page.reload` 回同一 URL 重新加载后整页回读（GUI 重载在本通道是空操作，不能用）。

## 6. 字段清单（两个实例）

### 6.1 在线简历页（银华基金实例，2026-09-17）

基础信息（姓名／手机／邮箱由账号带入）；
个人信息（性别、工作经验、最高学历、所在地、最近公司、证件类型+证件号码、出生日期）；
求职意向（当前薪资、期望薪资、期望城市）；
工作经历、教育背景（就读时间、学校名称、专业名称、学历）、实习经历（起止时间、公司名称、职位名称、工作职责）、
项目经验（起止时间、项目名称、职责、项目描述、项目中职责）、语言能力（语言类型、掌握程度、听说、读写）、
自我描述、获奖经历（获奖时间、奖项名称）。

应届生：工作经历留空并删除默认空记录（本系统允许删除，删除后保存不报错）。
语言档位：掌握程度=精通、听说=熟练、读写=精通（`CODEBUDDY.md` §二.$1）。

### 6.2 职位申请表（嘉实基金实例，2026-09-18，applyFormId=84152）

区块顺序：上传 → 个人信息 → 教育背景 → 实习经历 → 项目经验 → 语言能力 → 自我描述 → 获奖经历（+ 底部「更新说明」）。**无**工作经历、求职意向、技能证书、校园经历、大赛经历区块。

- 上传：`上传简历`、`上传照片`（两者带必填星号，附件须使用者手动传，本通道 CLI 无上传命令）。
- 个人信息：姓名、手机号码（区号下拉＋号码输入两段）、邮箱、性别、出生日期（**单个日期 input，值形如 `2001/07`**，非年月分列）、最高学历（由「学历」自动派生、不可直接填）、证件号码（类型下拉＋号码输入两段）、民族、毕业时间（**年＋月两个独立 input**）、招聘信息来源、政治面貌、国籍、生源地（级联地区选择器，展开后「热门地区」快捷标签类名含 `sd-Tag-text`，点「热门地区 北京市」即提交；省份按 A-G／H-K／L-S／T-Z 分组）。
- 教育背景：就读时间（年/月 × 起止四值）、学校名称（远程联想）、学院名称（普通输入）、专业名称（远程联想）、学历、GPA（得分/总分，普通输入）。
- 实习经历：起止时间（四值＋「至今」）、公司名称、职位名称、工作地点、工作职责（textarea）。
- 项目经验：起止时间、项目名称、职责（单行 input）、项目描述（textarea）、项目中职责（textarea）。注意「起止时间」与实习区块同名，**须按字段全局索引区分**。
- 语言能力：语言类型（**自由文本输入，无候选下拉**，直接写值即可）、掌握程度（字典下拉）。
- 自我描述：单条 textarea。
- 获奖经历：获奖时间（年＋月两值）、奖项名称（**该行只有名称一个输入框、无描述框**；库内要求带描述的条目须把描述并入名称，如「<学校>优秀学生干部（担任班级团支书期间获评）」）。

## [并入·DSH 侧 2026-10-05] 1 下拉控件（年／月／学历／掌握程度／国籍／招聘信息来源…）
- **开菜单必须点 caret**：点 `sd-Select-addon`（右侧箭头）开菜单；**点输入框本体无效**
- **选中走真实键盘**：开菜单后键入过滤词 → `Enter` 选中（长列表如年份 1926-2126 必须靠过滤，不能滚动找）
- 菜单项类名三类并存：`option-label`／`sd-Select-common-item`／`sd-Menu-content-item`——按类名取会漏，按文本取更稳
- **不要用 getByText 兜底**：页面同文本节点会被误点（命中页面别处的同名文字）
- **长页末条控件点击前必须手动滚动**：`scrollIntoViewIfNeeded()` 对表单末条（如获奖经历第 5 条）会失效——元素仍在视口外（实测 rect.y=838 > innerHeight=805），此时坐标点击直接抛 `CDP request timed out: Input.dispatchMouseEvent`（套重试循环会把脚本拖到超时）；处置＝按 `rect.y − innerHeight/2` 执行 `window.scrollBy(0, dy)` 后**重新测量再点**，`document.elementFromPoint(x,y)` 返回 null 即「落点在视口外」的即时判据（r7 首见、r22 宝洁轮复现，2 任务达标）


## [并入·DSH 侧 2026-10-05] 2 联想字段（学校／专业／民族）
- **值必须经菜单项选中才提交**：纯输入不入值，失焦即清空
- **「手动添加」的准确通道（2026-09-23 宝洁轮实测，四步）**：①在字段输入框键入任一检索词（库中无匹配）→ 下拉出现「No result」＋**按钮**「Add full name of school／major」；②点该按钮 → 下拉换成一整行**独立的补充输入框** `input[option-input]`（placeholder「Enter the full name of the school／major」，初始为空）＋primary 按钮「Add」；③在**补充框内** `fill()` 目标全称；④点「Add」提交。补全学校全称、专业（如高中「理科」）都走这条
- **脏值成因与处置**：检索框里的草稿会与手动值拼接——检索框有字时直接点「Add」提交的是空值；在检索框补字后再提交会拼出「<值A><值A>」「<值B><值B>」式脏值。**一旦落成脏值，最省事的修法是删掉该条目重建**（用条目的「删除本条 / Delete item」），不要就地编辑
- **提交按钮必须就地定位（2026-09-24 申万菱信轮实测）**：补充框与其「添加」按钮同在一层下拉面板内，取按钮要**从补充输入框 `parentElement` 逐级上溯，取第一个可见的「添加」按钮**；用「全页最后一个 `添加` 按钮」会点到别的区块（工作经历／奖惩区）的添加键——表现为补充框已 `fill()` 成功、点击也返回成功，但字段值始终为空，易误判为写入通道问题。补充框 placeholder 随租户变化（申万菱信为「请输入就读学校全称／请输入就读专业全称」），按 `placeholder*="全称"` 匹配
- 清空／重输用 Playwright `fill()`：`page.keyboard` 不把 `Control+a` 识别为组合键，会把字面 `a` 插进检索词（实测检索词变成「a会计学」查无选项）


## [并入·DSH 侧 2026-10-05] 3 落库判据
- 同一租户的表单区块差异大（嘉实 applyForm 含项目／获奖／自我描述，雀巢仅 7 段，宝洁 12 区块：申请信息／上传／个人信息／教育背景／实习经历／工作经历／项目经验／获奖经历／渠道来源／其他信息／声明／更新说明），**区块清单逐租户侦察**，不套用其他租户
- 保存成功以「整页刷新／服务端重拉后数据仍在」为准；Moka 职位申请表**无保存按钮、无自动保存**（2026-09-23 宝洁轮第 2 次、2026-09-24 申万菱信轮第 3 次实测：全页只有「预览并提交 / Preview and submit」，数据只存在于当前页面，**切走路由即全丢**）→ 先把风险报告用户，填写期间禁止刷新／导航，并让用户在同一页面内复核与提交
- **租户可跑在自定义域上**：申万菱信租户为 `job.swsmu.com/campus_apply/swsmu/74260#/job/<jobId>/apply?applyFormId=<id>`，主机名不含 mokahr → 判框架只看 DOM 的 `sd-` 前缀类名（`sd-Select-addon`／`sd-Dropdown-dropdown`／`sd-Input-*`／`sd-Tag-*`），不按域名判
- **勾选框（`confirm_info`，如「承诺」「本人确认已上传附件」）**：点 `input[type=checkbox]` 无效（JS click 也不变），要点它外层的 `label`／`sd-Checkbox` 包裹元素才勾上；勾上后**同一区块会新插入带星必填字段**（申万菱信承诺区 = 应聘人签名 ＋ 签署日期），须一并填写
- **多条目区块的「添加」按钮点击通道不统一**：同一租户内教育／技能／工作经历的「添加」按钮 Playwright `click()` 生效（申万菱信实测），项目经验区块的同一个按钮 `click()` 返回成功却**不加行**，改用页面内 JS 派发 `mousedown/mouseup/click` 才加行 → 加行后**必须回读行数**确认（`[class*="apply-fields-"]` 计数），只信行数不信点击返回值
- **宝洁租户专属（`recruit.pg.com.cn`，申请页 applyFormId=107810）**：年／月是普通 `sd-Select` 下拉（**不是**雀巢那种日历面板）；「校招面试站点」是 cascader 两级（北京市→北京，先点左列再点右列）；「渠道来源」是 14 项自有清单、**没有库内口径「学校就业网」**；提交链带易盾（yidun）短信／语音验证，脚本不可完成，须用户在场操作


## [并入·DSH 侧 2026-10-05] 4 上传简历＝服务端解析重填，必须最后做
- **上传「上传简历」会触发服务端解析并重填申请表，覆盖已填内容**（2026-09-24 申万菱信轮实测，事故级：工作经历 4 条→1 条空行、项目经验 2 条→1 条空行、教育背景高中条整行被删、教育起止时间被写回废弃口径〔2024-06→2024-07〕、求职意向「可接受岗位调剂」tag 被清空）
- **顺序**：先把整表填完 → **最后**再上传简历 → **立即整表回读**，逐项修复被覆盖的区块；不要在填表中途上传，也不要在上传后直接交付
- **解析是异步多波写回，修复前必须确认表单已稳定**（2026-09-24 申万菱信轮实测）：上传后 15 秒的快照看似只丢了工作经历／项目／教育行，按快照修完之后，约 1 分钟内第二波写回又清掉了社会关系里的父母姓名／工作单位（同一轮内 5 个区块先后被覆盖）。做法：连拍两次全表快照、间隔 50 秒，两次完全一致（字段数＋逐格值）才判定稳定，然后才逐项修复；修完再拍一次确认没有第三次覆盖
- **修复判据用「解析前快照」而不是记忆**：动手填表期间先落一份 `.dsh/tmp/pre-parse-snapshot.json`（区块／行／标签／显示值），上传解析后再拍一份逐格 diff；注意同一区块内会有重名标签（如两处「子女情况」、多处「备注(原因说明)」），diff 脚本按键去重会把其中一处漏报，重名字段要单独复核
- 上传位是三个独立 `input[type=file]`：上传简历（`file_upload`，**会解析**）／上传附件（`attachment_upload`，不解析、可选）／上传照片（`portrait_upload`，带星必填）；后两者可用 Playwright `setInputFiles()` 直填（隐藏 input 也能设），照片落库后字段内出现 OSS 缩略图


## [并入·DSH 侧 2026-10-05] 5 子控件形态（日期与多选 tag）
- **日期类控件两种形态**：`day_info` 走后端日历面板——点输入框 → 点 `sd-basic-selector-year` → 点年格 → 点 `sd-basic-selector-month` → 点月格（如一月中文名）→ 点日格；该输入框多为 `readonly`（键盘输入无效、不落库），必须走面板
- **日历面板是「点击开关」，且菜单首个点击常被吞（2026-09-24 实测，同轮踩到 3 次）**：面板开着时再点输入框会把它**关掉**（症状：这次 eval 返回 `no-panel`／`no-span`，而实际是面板刚被自己关掉）；正确姿势是**先探测面板是否已开**（`span[class*="basic-selector"]` 里出现「…年／…月」文本即为开），开着就直接用、不要点；关着才点输入框，且**点完要复检**，未开则 `Escape` ＋ 重点，最多重试 3～4 次（实测第 3 次才开）。同理，`date_info` 起止年月有 4 个 addon（年／月／年／月），首次点前两个常返回 `no-panel`，加 Escape＋重试后即开
- **多选 tag 误选的清理**：多选字段（如「是否可接受岗位调剂」）一旦选错，正解是 JS 点该 tag 的 `sd-Tag-close` 关闭图标删除该 tag，再重选；只按选项文本点会追加第二个 tag（两个互斥选项同时挂上）
